# 克莱门莎桌宠

克莱门莎桌宠是一个面向 Windows 11 x64 的《明日方舟》同人桌面伴侣。克莱门莎会在屏幕底部散步。点一下她手里的稿纸，可以读到她留下的手记；双击，她会化作小蝠鲼，在当前应用窗口上方巡游。角色小人取自默认基建模型，手记、桌面互动和新增台词为同人创作。[PRTS 克莱门莎角色页](https://prts.wiki/w/克莱门莎)

## 当前可以体验什么

- **与角色互动。** 点头部或身体有不同回应；长按提起时，腰部承重，头和四肢自然下垂。她稍稍移开目光，右上方浮起爱心。松手后会落回地面。
- **一边工作，一边陪伴。** 桌宠以透明窗口绘制，轮廓外的点击可落到下方应用。右键角色或托盘图标可读手记、变身、隐藏或召回。三篇手记和动画随 EXE 提供，断网也可使用。
- **保留使用习惯。** 重启后恢复角色形态、位置、鼠标穿透偏好和上次读到的篇目。

## 下一版想做什么

让她也能挑合适的时候开口。比如傍晚第一次见面，她问一声好；到了用户设定的间隔，她邀请博士一起喝口水；偶尔，她会就手稿里的一句话征求意见。用户可以接下这个话题，也可以随时从托盘主动找她聊。问候、提醒和对话是下一阶段的开发内容。

这一阶段用本地作者写好的话题和分支实现短对话。称呼用“博士”和“您”，关心以邀请表达。用户说“晚点吧”，她会记下这次选择，把谈话留到合适的时候。

## 从哪里开始

解压后双击 `dist/ClementiaPet.exe` 体验当前版。在项目根目录执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1` 可用 Windows 系统编译器重新构建。源码使用 C#、Windows Forms 和 Win32 分层窗口。交给开发 AI 时，先读本介绍，再读下一阶段任务书。[下一阶段开发交接](./下一阶段开发交接.md) · [构建与桌面测试](../README.md)
